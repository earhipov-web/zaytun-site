# ZAYTUN: сайт-пример

React 19 + TypeScript + Tailwind CSS 4, структура shadcn (`src/components/ui`, `@/lib/utils`).

```bash
npm install
npm run dev
```

Все тексты, цены, мастера, акции и афиша лежат в `src/data/site.ts`.
Акции и афиша: примеры, их нужно заменить постами из https://t.me/fitnes_spa_Zaytun.
